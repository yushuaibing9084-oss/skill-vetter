# Skill Vetter v0.2.0 优化思考记录

**日期**: 2026-04-02  
**触发**: 朋友的反馈  
**核心主题**: 从客观评分到个性化匹配，从工具思维到助手思维

---

## 朋友的原始反馈

> "skill要根据自己的知识范围，理解层次和当前使用需要来选择。最终决定skill使用效果评估也有很强的个人主观色彩，语言解析与理解，预期效果与管理都是可以踩到的点。"

---

## 深度解读

### 1. "根据自己的知识范围，理解层次和当前使用需要来选择"

**洞察**: 当前评估框架忽略了用户自身因素

| 传统评估 | 忽略的用户因素 |
|---------|---------------|
| 来源可信度 | 用户的技术理解能力 |
| 技术价值 | 用户的实际需求场景 |
| 社区反馈 | 用户的时间/预算约束 |
| 下载量 | 用户的隐私敏感度 |

**问题**: 一个评分 90 分的 Skill，对新手可能是灾难；一个评分 70 分的 Skill，对专家可能刚刚好。

**解决**: 引入**用户画像系统**，计算个性化匹配度

### 2. "有很强的个人主观色彩"

**洞察**: 客观评分无法替代主观体验

**问题**: 
- 同样的功能，有人觉得"强大"，有人觉得"复杂"
- 同样的价格，有人觉得"便宜"，有人觉得"贵"
- 同样的速度，有人觉得"快"，有人觉得"慢"

**解决**: 
- 不仅告诉用户"这个 Skill 评分多少"
- 更告诉用户"这个 Skill 为什么适合你/不适合你"
- 让推荐**可解释**

### 3. "语言解析与理解"

**洞察**: 用户往往不知道自己要找什么 Skill

**问题**:
- 用户说"我想处理音频"，但不知道应该用 transcription、tts、还是 audio-processing
- 用户描述的是**问题**，不是**解决方案**

**解决**: 
- 支持自然语言需求输入
- 解析用户意图，匹配 Skill 能力
- 对话式需求挖掘

### 4. "预期效果与管理"

**洞察**: 用户踩坑往往是因为预期与实际不符

**常见踩坑场景**:
- 以为"AI 视频生成"能做出电影级效果，实际只能做 5 秒短视频
- 以为"免费"真的免费，实际有隐藏成本
- 以为"一键安装"真的简单，实际需要配置环境

**解决**: **预期管理系统**
- 明确告知：能做什么 ✅
- 明确告知：不能做什么 ⚠️
- 明确告知：隐藏成本 💰
- 生成「使用前必知」清单

## 优化方案

### 新增模块一：用户画像系统 (user-profile.js)

```javascript
// 核心功能
- 交互式收集用户画像（技术背景、使用场景、隐私要求、时间预算、成本约束）
- 计算 Skill 与用户的四维匹配度（技术/隐私/时间/成本）
- 生成可解释的推荐理由
```

**关键设计**:
- 画像收集用对话式，降低用户负担
- 匹配度计算透明，告诉用户为什么匹配/不匹配
- 支持本地保存，下次直接使用

### 新增模块二：预期管理系统 (expectation-manager.js)

```javascript
// 核心功能
- 维护 Skill 预期数据库（能做什么/不能做什么/隐藏成本）
- 解析用户自然语言需求
- 对比用户需求与 Skill 能力，识别不匹配
- 生成「使用前必知」清单
```

**关键设计**:
- 预期数据众包：让用户贡献真实使用体验
- 意图解析：从"我想处理音频"提取 use_case=audio_processing, constraint=privacy
- 不匹配警告：明确告知用户可能踩的坑

### 新增模块三：交互式推荐 CLI (cli-interactive.js)

```javascript
// 三种使用模式
1. skill-vetter check <skill-id>
   → 快速评估，适合已知 Skill

2. skill-vetter check <skill-id> --intent "..."
   → 带需求评估，验证匹配度

3. skill-vetter recommend
   → 智能推荐，对话式需求挖掘
```

**关键设计**:
- 推荐结果按匹配度排序，而非综合评分
- 每个推荐都有「为什么推荐」的解释
- 支持查看详细评估报告

## 核心理念升级

### 从工具思维到助手思维

| 工具思维 | 助手思维 |
|---------|---------|
| 你输入 Skill ID，我给你评分 | 你告诉我需求，我帮你找合适的 |
| 客观中立，一视同仁 | 个性化推荐，因人而异 |
| 只告诉你"是什么" | 还告诉你"适不适合你" |
| 功能罗列 | 预期管理 |

### 从客观评分到个性化匹配

```
旧模式:
用户: 我想安装 XXX
工具: XXX 评分 72/100，风险 MEDIUM
用户: 那我该不该装？
工具: ...（沉默）

新模式:
用户: 我想解决 YYY 问题
工具: 基于你的技术水平和隐私要求，推荐 ZZZ
      匹配度 95/100，因为：
      ✅ 技术难度与你匹配
      ✅ 符合你的隐私要求
      ⚠️ 需要 30 分钟配置时间
用户: 好，我试试
```

## 实施结果

### 代码变更
- 新增 `user-profile.js` (240 行)
- 新增 `expectation-manager.js` (260 行)
- 新增 `cli-interactive.js` (340 行)

### 功能亮点
1. **对话式推荐**: `skill-vetter recommend` 交互式收集需求
2. **意图匹配**: `check --intent` 验证 Skill 是否符合需求
3. **预期管理**: 每个报告都包含「能做什么/不能做什么/隐藏成本」
4. **可解释推荐**: 不仅说匹配度多少，还说为什么
