# 竞品调研报告

**调研时间**: 2026-03-30  
**调研目标**: 是否存在同类 Skill/Package 评估工具

---

## 发现的相关项目

### 1. Dep-Oracle
- **GitHub**: ertugrulakben/dep-oracle
- **定位**: Predictive dependency security engine
- **功能**: Trust Scores for npm/Python packages
- **特点**: 
  - 检测僵尸包、typosquats、供应链风险
  - 在成为 CVE 之前预警
  - 有 Trust Score 概念

**与我们的区别**:
- 他们专注**安全**，我们专注**综合质量**
- 他们有 Trust Score，但维度不明
- 他们是预测性，我们是评估性

---

### 2. Sentinel Package Manager
- **GitHub**: dream-horizon-org/sentinel
- **定位**: 阻止恶意包安装
- **功能**: 
  - 安装前拦截
  - 795+ 黑名单
  - 实时检查 (OSV/GitHub/Snyk)

**与我们的区别**:
- 他们是**拦截工具**，我们是**评估工具**
- 他们基于黑名单，我们基于多维度评分
- 他们是防御性，我们是决策辅助

---

### 3. Shai-Hulud 系列
- 多个相关项目 (shai-hulud-detector, shai-hulud-malicious-packages)
- **定位**: 检测恶意 NPM 包
- **功能**: 供应链攻击检测

**与我们的区别**:
- 专注**恶意软件检测**
- 不评估一般质量

---

### 4. Package Firewall (pfw)
- **GitHub**: thebasedcapital/pfw
- **定位**: Self-hosted supply chain security
- **功能**: 拦截 npm/pip/cargo，4 个漏洞源

**与我们的区别**:
- 企业级防火墙
- 技术导向，不评估开发者可信度

---

### 5. npm 自带工具

#### `npm audit`
- 检测已知漏洞
- 基于 npm security advisories
- **局限**: 只关注安全，不关注质量

#### `npm view`
- 查看包元数据
- **局限**: 原始数据，无综合评估

---

## 核心发现

### 现有工具的共同特点

| 工具类型 | 代表 | 关注点 | 缺失 |
|----------|------|--------|------|
| 安全扫描 | npm audit, Snyk | 漏洞 | 质量、可持续性 |
| 恶意检测 | Shai-Hulud | 恶意代码 | 一般质量评估 |
| 拦截工具 | Sentinel, pfw | 阻止安装 | 评估报告 |
| 信任评分 | Dep-Oracle | 安全风险 | 透明度、技术价值 |

### 市场空白

**没有发现任何工具做我们做的事**:
- ❌ 多维度综合评估（来源 + 透明度 + 可持续性 + 技术 + 安全）
- ❌ 针对 AI Skill 生态（而非传统 npm 包）
- ❌ 开源透明的评估标准
- ❌ 社区共治的评估机制

## 结论

### 竞品情况
- **直接竞品**: 无
- **间接竞品**: 多个安全工具
- **市场空白**: ✅ 存在

### 机会
我们是**第一个**做 AI Skill 综合评估的工具，有先发优势。

### 风险
- 概念太新，用户教育成本高
- 需要建立信任
- 评估标准需要长期验证

---

## 建议

1. **强调差异化** —— 不是安全工具，是综合质量评估
2. **教育市场** —— 解释为什么需要多维度评估
3. **快速迭代** —— 利用先发优势建立标准
4. **建立联盟** —— 与 Agent 平台合作，成为基础设施

---

**调研结论**: 市场存在空白，Skill Vetter 有独特价值主张。
