## 如何使用

运行以下命令生成你自己的评估报告：

```bash
# 克隆仓库
git clone https://github.com/yushuaibing9084-oss/skill-vetter.git
cd skill-vetter
npm install

# 评估任意 Skill
node src/cli-interactive.js check <skill-id>

# 示例
node src/cli-interactive.js check inference-sh/skills@ai-video-generation
```
